Discord Bot • Audio Engineering 02 / 04

Discord Spotify Music Bot

A high-performance, scalable Discord music bot built with TypeScript, Discord.js v14, and a Lavalink v4 audio server. Supports direct Spotify tracks, albums, playlists, and YouTube Music with an O(1) in-memory LRU stream cache, next-track prefetching, live lyrics, custom bookmarks, and a tiered priority rank queue.

  • Offloaded voice streaming via Lavalink v4, Shoukaku & Kazagumo
  • Interactive button controller, slash commands with autocomplete & live lyrics
  • 2-stage resilient yt-dlp stream resolver with zero-byte SSD overhead
TypeScript Node.js Discord.js v14 Lavalink v4 Kazagumo Shoukaku Spotify Web API yt-dlp Java
